# Portfolio — notes for agents

Vite + React 19 + TypeScript + Tailwind CSS v4 (shadcn/ui configured). The
approved design is final: changes must not alter rendered output unless that
is the explicit task.

- `npm run dev` — dev server (client-rendered).
- `npm run build` — image variants, typecheck, client + SSR build, then
  `scripts/prerender.mjs` writes static HTML for every route, `404.html`,
  `robots.txt` and `sitemap.xml` into `dist/`.
- `npm run preview` — serves `dist/` with Vercel-style clean URLs and 404s.

Conventions:

- Content lives in `src/data/*` (typed in `src/types`); per-route `<head>`
  tags in `src/lib/seo.ts`.
- Styles: `src/styles/index.css` imports every stylesheet in a fixed order
  that preserves the original cascade. Component styles sit next to their
  component and are in Tailwind's `components` layer.
- Images: use `@/components/ui/Image` with `/public` paths; resized WebP
  variants are generated by `scripts/optimize-images.mjs`.
- Scroll-triggered entrance animations are declared in
  `src/data/scrollTimelines.ts` and run by `src/lib/scroll-timeline.ts`.
